# set-up-notes
A repository is where you store code in the cloud
Open Databricks Home page and press on top right account button and go into seetings
In settings press "Linked Accounts" press "Add Git credentials"
Press "Link and "Authorise"

# To clone a Repo in Databricks 
Create a Repo in Github
Go into workspace in Databricks 
Open "Repos" folder 
Press "create a Repo here" or "Create a repo folder" this will open an add repo page where you can paste a GIT repo URL
Copy the URL from the Github repo and it will auto fill in the rest of the boxes 

Once inside the Git Repo in databrick you can start editing by pressing open in editor 
This lets you create notebook, md files and import exisiting things

# How to Push from DataBricks to Github
Inside you repo folder next to the title press "Main"
Select what you want to be moved 
Write something in the "commit message"
Then press "Commit and Push"
Then code should be saved into your github repository
